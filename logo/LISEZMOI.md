# Logo KYNO

Un K fait de blocs, comme une chaîne de blocs. Le bloc en pointillé, en haut à
droite, est le **prochain bloc** : celui que les mineurs cherchent.

| Fichier | Usage |
|---|---|
| `kyno-logo.svg`, `kyno-logo-1200.png` | logo complet, sur fond clair |
| `kyno-logo-sombre.svg`, `kyno-logo-sombre-1200.png` | logo complet, sur fond sombre |
| `kyno-symbole.svg`, `kyno-symbole-512.png` | symbole seul, sur fond clair |
| `kyno-symbole-sombre.svg`, `kyno-symbole-sombre-512.png` | symbole seul, sur fond sombre |
| `kyno-icone.svg`, `kyno-icone-*.png`, `favicon.ico` | icône d'onglet, d'application ou de profil (fond clair intégré, lisible partout) |
| `kyno-carte-sociale.png` | aperçu des liens partagés (1280 × 640), par exemple l'aperçu social du dépôt GitHub |

## Règles

- Laisser autour du logo un espace libre d'au moins la largeur d'un bloc.
- En dessous de 24 px, utiliser l'icône (`kyno-icone-16.png`,
  `kyno-icone-32.png`, `favicon.ico`) plutôt que le symbole seul.
- Ne pas déformer, recolorer, ombrer ni remplir le bloc en pointillé.
- Le logo désigne le projet Kynovara : ne pas l'utiliser d'une façon qui
  laisse croire à une vente de KYNO ou à un produit officiel (voir
  [AVIS.md](../AVIS.md)).

Le nom est dessiné avec **Archivo** (KYNO : Expanded ExtraBold ; KYNOVARA :
SemiBold élargi), converti en tracés : aucune police n'est nécessaire pour
